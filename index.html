車体走行テストの
反省点・改善策・考察

反省点

・ 返ってくる位置のズレとUターン時間（コード内のTIME TURNの値）の相関関係を表にしておき，1回目のずれを参考に微調整を加えたうえで，2回目の走行に挑むべきだった．
TIME TURNの値 (ms) 位置のズレ (mm) 備考
5350 235 1回目走行結果
5150 145 2回目走行結果
4827 0 理論上の最適値

具体的な改善策

・ 事前にTIME TURNの値を変えた場合の車体が返ってくる位置のズレの変化を表にしてまとめておく．

・ 1回目の本番走行で生じる「車体が返ってくる位置のズレ」に基づき，本番2回目直前に数値を微調整する．

考察

本番1回目のズレ（TIME TURNの値）
235mm (5350ms)
本番2回目のズレ（TIME TURNの値）
145mm (5150ms)
・ TIME TURNの値を200msだけ短縮させることで，ズレが90mm改善したことから，TIME TURNを4827㎳にすることで，ズレが0となる位置に帰ってこれたと考える．
ただし，板の歪みが車体の返ってくる位置のズレに大きく影響していることは否めない．理想としては，物理的な路面形状に強い車体構造，又はセンサーによる角度補正の導入についても検討するべきだったと考える．

今回使用したコード

#include <Arduino.h>
#include <Servo.h>

// ① ピン設定
const int PIN_MOTOR_PWM = 5;
const int PIN_MOTOR_DIR = 7;
const int PIN_SERVO     = 9;
const int PIN_SENSOR    = 2;

// ② 動きの設定
const int SPEED          = 255;
const int ANGLE_STRAIGHT = 88; 
const int ANGLE_TURN     = 45;

// ③ 時間の設定（Uターンだけは角度制御のために時間を使用）
const int TIME_TURN      = 5350; 

Servo myServo;
int stage = -1; 

void motorOn()  { analogWrite(PIN_MOTOR_PWM, SPEED); digitalWrite(PIN_MOTOR_DIR, LOW); }
void motorOff() { analogWrite(PIN_MOTOR_PWM, 0); digitalWrite(PIN_MOTOR_DIR, LOW); }

void setup() {
  pinMode(PIN_MOTOR_PWM, OUTPUT);
  pinMode(PIN_MOTOR_DIR, OUTPUT);
  pinMode(PIN_SENSOR, INPUT_PULLUP);
  myServo.attach(PIN_SERVO);

  motorOff();
  myServo.write(ANGLE_STRAIGHT); 
  delay(1000); 
}

void loop() {
  if (stage == -1) {
    if (digitalRead(PIN_SENSOR) == LOW) {
      delay(500); 
      stage = 0;
    }
  }
  else if (stage == 0) {
    myServo.write(ANGLE_STRAIGHT);
    motorOn();
    while(digitalRead(PIN_SENSOR) == LOW) {
      delay(10); 
    }
    motorOff();
    delay(1000);
    stage = 1;
  }
  else if (stage == 1) {
    if (digitalRead(PIN_SENSOR) == LOW) {
      delay(500);
      myServo.write(ANGLE_TURN);
      motorOn();
      delay(TIME_TURN);
      myServo.write(ANGLE_STRAIGHT);
      while(digitalRead(PIN_SENSOR) == LOW) {
        delay(10);
      }
      motorOff();
      delay(1000);
      stage = -1;
    }
  }
}
